## 文献标准基线

所有发布模板均显式选择2015版著录基础，避免无年份别名随TeX环境切换2025版。海科职办法明确引用2015标准；海经为2015样式的排序衍生版；其余学校是**本项目暂定的可复现基线，不宣称当届学院已要求2015版**。如学院要求其他年份，应另建适用范围明确的配置并补测试。
