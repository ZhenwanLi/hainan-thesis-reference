# 琼台师范学院结构工作稿（关键版式待核对）

按[2021工作规定](https://jwc.qtnu.edu.cn/info/1021/4781.htm)的组成结构起草。2026/2027材料下载需验证码，未取得实体，不绕过；工作规定另引用专门撰写规范，不能从工作规定推断字号、页面和官方封面。

当前提供封面、独创性及授权声明、中英文摘要、目录、正文、参考文献、附录、致谢。**封面字段及声明均为占位/本地示例，不是学校原文。** 默认A4上下25.4、左30、右25mm、小四1.5倍、三级标题、前置罗马/正文阿拉伯、图表公式按一级节重置，全部是待核对参数。

个人信息改main.tex，正文与附录在chapters/，书目refs.bib，运行`bash compile.sh`。默认开放字体预览，依赖与日志见[构建说明](../../docs/BUILD.md)。文献明确2015基线，不宣称学院要求已确认。

研究设计、观察表、流程图和访谈提纲是工具例子，没有真实课堂、样本数量或调查结论。取得当届包后重点核对页面、封面、两份声明、摘要/目录字号、标题编号、文献与归档要求。
