# 海南热带海洋学院（非官方历史格式重排）

依据[教务处历史配套资料](https://jwc.hntou.edu.cn/sjjx/bylw/202005/t20200519_31588.html)整理格式信息，不附Word原件和过程管理表。没有证据证明所有学院当届仍用该格式。

| 入口 | 类别 | 特点 |
|---|---|---|
| main.tex | 理工 | 四级阿拉伯编号；图表公式按一级节重置 |
| main-humanities.tex | 文经管法 | 一、㈠、1、⑴；独立研究示例 |
| main-foreign.tex | 外语 | 英文正文、Acknowledgements在CONTENTS前 |
| main-art.tex | 艺术 | 自定设计说明与图版占位；不强求与理工同等页数 |

用`bash compile.sh <入口名去掉.tex>`编译。个人信息与类别条件在main.tex；英文姓名、导师、日期有单独字段；长字段允许换行，第二导师非空时输出。

理工/文经管法/外语正文按旧Word正文节属性设置上下26mm、左右31.7mm；艺术按明文上30/下25/左30/右20mm。旧Word前置/正文节属性不一致，当前封面是重排，并非等比例复制。默认Fandol预览，不等同原封面字体；行距理工/文经管法/艺术20bp，外语22bp。

论文之外的任务书、开题、中期、审阅、评阅、答辩表及整册总目录不自动生成，请自行取得当届官方材料。旧校名、制表年更改属于本地调整，不代表学校发行新版。文献暂以2015版为可复现基线，待学院确认。全部数据与文字为写作提示，不报告真实研究成果。

预览与学校字体模式、依赖及退出状态详见[构建说明](../../docs/BUILD.md)。中间文件在`.build/<入口>/`，成功后更新同名PDF；失败保留旧PDF。许可与适用边界见根目录文档。
