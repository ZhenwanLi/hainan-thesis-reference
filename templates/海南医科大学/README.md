# 海南医科大学药学院本科参考模板

**仅依据[药学院2019规范](https://www.muhn.edu.cn/yxy/info/1008/1509.htm)，不代表全校本科或研究生，不保证2026仍有效。** 本项目不提供研究生学术型/专业型模板，虽已有官方通知证实它们存在。

实现A4上下25.4、左右31.7mm；正文小四1.5倍；结构式中英摘要各一页；目录；前言、材料与方法、结果、讨论、结论；参考文献、可选附录及致谢。图表全文连续，三线表，脚注逐页重置，正文页眉校名与右上页码。当前校名替换了旧规范中的“海南医学院”，是本地改动。

封面和声明均为明确标注的占位页，不是取得的学院原件。原规范中参考文献与致谢前后顺序自相矛盾，当前采用正文→参考文献→可选附录→致谢，须学院确认；目录编号表述也需核对。文献用2015版基线近似，不声称完全复刻旧样例标点。

修改main.tex信息、style.tex格式与chapters/正文，运行`bash compile.sh`。默认开放字体只供预览，详见[构建说明](../../docs/BUILD.md)。中间文件在`.build/main/`。所有数据为合成例子，不能用于医学、药效或安全性推断；不预填伦理审批或实验结果。
