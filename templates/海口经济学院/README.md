# 海口经济学院（非官方2026附件格式重排）

依据海经教务〔2025〕54号配套附件13格式信息；原件不随项目分发，来源及附件地址见[来源清单](../../sources/README.md)。附件12是整册封面，本模板不生成完整过程材料整册。

**官方要求电子文档为Word。PDF可编译不代表学院允许LaTeX替代Word。**

- 页面A4上/下30、左25、右20mm；正文小四、1.5倍行距；默认开放字体仅供预览。
- 封面字段可换行，声明页只提供提示，原文必须自行向学院取得。
- 目录无页码，中文摘要页开始页码1；图表全文连续，公式标签“（1）式”；脚注每页重置。
- 表号左、题名中、单位右，在table内caption前用`\tableunit{单位：元}`设置；下一表自动清空。长题仍须人工检查。
- 正文与附录在chapters/，个人信息在main.tex，书目在refs.bib。
- 正式论文原则上至少8000字、设计至少5000字、文献至少15篇；本例不用于满足工作量。

## 本地书目样式

`hkcu-gbt7714.bst`由上游gbt7714-2015-numeric v3.1.1衍生，保留LPPL和署名，仅改排序：中文→外文，各语种内论文→著作→其他，同类年份新到旧，同年按键稳定。非官方bst。

article/inproceedings/conference/phdthesis/mastersthesis默认论文；book/inbook/incollection默认著作。其他类型放在组后、同年顺序均为本地默认，待学院确认。可用`hkcuclass={paper}`、`{book}`或`{other}`覆盖分组；中英混排建议显式language。缺失/非法年份会警告，不应忽略。只输出引用条目，不靠nocite预排。

运行`bash compile.sh`。详细依赖、字体、日志、失败保护见[构建说明](../../docs/BUILD.md)。单独复制本目录即可使用，不需复制上级脚本。文献标点、副标题及个人论文的所有换行仍需人工对照学院要求。
