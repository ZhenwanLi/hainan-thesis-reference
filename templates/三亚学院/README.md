# 三亚学院结构工作稿（待学院备案版式）

[2026届通知](https://jw.sanyau.edu.cn/2025/1106/c1971a406546/page.htm)要求按2024修订工作规范开展；学校文科/工科版式仅供参考，**学院按学科特点确定并报教务处审核备案**。本稿不是全校统一版式，未取得所属学院备案Word。

有封面及声明占位、中英摘要、三级目录、研究设计、图表公式、参考文献、致谢与附录。A4上30/下25/左30/右20mm、小四1.5倍、标题字号、罗马前置页码和页眉均为本地默认，待核对。文献2015版也是本项目基线，而非已经核实的学院条款。

信息改main.tex，格式style.tex，正文chapters/，运行`bash compile.sh`。默认开放字体预览，详见[构建说明](../../docs/BUILD.md)。示例未做调研或测试，不预填调查人数、企业成果、伦理编号或性能结论。

正式使用先取得学院当届备案版式，确认封面、声明原文、章节组织、文献、签字、检测与电子提交形式。
