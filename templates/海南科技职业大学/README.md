# 海南科技职业大学结构工作稿

依据[2026第三次修订管理办法](https://jwc.hnkjedu.cn/news/29534)，自2026届执行。第二十八条列明题目、中英摘要、关键词、目录、正文、参考文献、致谢及附录；**专门书写规范与模板实体未取得**，不能把本稿当成复刻版。

A4上30/下25/左30/右25mm、小四1.5倍、封面、页眉页码、标题、按节图表公式编号都是待核对的本地默认。管理办法明确引用2015文献标准，本稿固定2015版样式，但排序、标点和具体模板仍应原件校正。

示例有需求追踪表、结构图、公式、测试记录框架、代码和长表。未实施测试标为待实际测试，不提供虚构性能。正式正文不少于6000字，本稿不凑字数也不满足提交篇幅。纸电双套归档按当年清单执行，不附官方过程表。
