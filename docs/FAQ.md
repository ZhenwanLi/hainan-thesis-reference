# 常见问题

[返回首页](../README.md) · [安装与构建](BUILD.md) · [报告问题](https://github.com/ZhenwanLi/hainan-thesis-reference/issues/new/choose)

## 这是学校官方模板吗？能直接交吗？

不是。这里是非官方参考工程，部分材料只有历史规范或组成结构依据。编译成功不代表学校审核通过，更不代表学院允许用 PDF 替代 Word。请先核对首页学校表、对应学校 README 和当届学院要求。

## 海南大学、海南师范大学的模板在哪里？

本仓库仅在[来源索引](../sources/README.md)提供上游链接，不捆绑这两校工程。海南医科大学目录也仅针对药学院2019本科规范，不是全校或研究生模板。

## 新手从哪里开始？

1. 阅读[安装指南](BUILD.md)，准备工具链。
2. 在项目根目录运行 `python3 tests/preflight.py`。
3. 选择学校，先编译未修改的示例，再修改内容。
4. 阅读该目录 README，核对个人字段、正文入口和书目文件。
5. 对照学院要求检查封面、声明、字体、页码及提交形式。

各校结构略有不同：一般从 `main.tex`、`chapters/`、`refs.bib` 开始；热海其他类别有独立入口。请勿全局替换宏命令，也不要将示例研究内容当作真实结果。

## 能用 Overleaf、Windows 或 macOS 吗？

尚未完成这些环境的整链验证。当前测试目标为 Linux、Bash、Python 3.10+、TeX Live 2026 和 Poppler。Overleaf 的编译器、宏包版本、字体和脚本执行方式与本地环境不同，不能仅凭“使用 XeLaTeX”保证兼容。Windows 可考虑 WSL，但本项目没有给出实测通过承诺。

## 为什么没有直接提供 PDF 或字体下载？

当前公开版以源码和文档为主，生成 PDF、日志及官方原始附件默认不入库。PDF 可能被误当作学校认可样例，分享前还需重新核对个人信息与字体。默认预览字体由 TeX Live 提供；不分发微软字体，学校模式需用户自行合法安装。

## 中文字体和学校要求不一样，正常吗？

默认采用开放字体预览，不是学校字体验收模式。更换字体会改变字宽、换行和分页。所需学校字体已合法安装时，可按[构建指南](BUILD.md)设置 `THESIS_FONTS=school`；即使该模式编译成功，也仍须核对具体要求。

## 已有 PDF，为什么脚本仍报告失败？

工程只有完整编译成功才替换最终 PDF，失败会保留旧文件。请看命令退出码、第一处错误及 `.build/<入口>/<入口>.log`，不要把旧 PDF 当作本次成功的证据。不要多个进程同时编译同一目录的同一入口。

## 参考文献为什么固定为 2015 版？

使用显式 `gbt7714-2015-numeric.bst` 是为避免无年份别名随工具链变化。它不是本项目对所有学院要求的认定，详见[文献基线](../sources/README.md#文献标准基线)。海经目录有保留 LPPL 和上游署名的派生排序样式，不能当作官方发布样式。

## 如何反馈问题或补充最新版规范？

使用[反馈表单](https://github.com/ZhenwanLi/hainan-thesis-reference/issues/new/choose)。编译问题请提供系统、TeX Live 版本、学校、入口、字体模式和脱敏后的第一处错误；格式问题请提供学院、学位层次、届别与官方公开 URL。不要直接上传真实论文、学号、签名、完整私人日志或未经确认许可的附件。
