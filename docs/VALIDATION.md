## 修复与测试注意

旧圆圈脚注用未完全展开的symbol表达式，写到标签中可能不固化编号。发布版改为可展开圆圈字符映射，测试比较同页①/②及跨页重新①，不仅检查没有警告。

纯字体预览使用文件名加载TeX字体；学校模式在缺字体时明确失败，不偷偷替换。文献2015基线固定详见sources/README.md。

测试临时副本使用Python标准临时目录机制，支持系统TMPDIR；源码目录无home或特定平台临时路径。日志、失败夹具、生成PDF仅存本地reports/.build，不加入源代码发布清单；负面年份夹具故意产生BibTeX警告，与正式日志零警告不矛盾。

## CI与可复现性边界

2026-10-23，提交 `abca5af` 已在 GitHub Actions 的 `ubuntu-24.04` 托管 runner 上完成从网络安装 TeX Live 2026 到全部测试的验证：[成功运行记录](https://github.com/ZhenwanLi/hainan-thesis-reference/actions/runs/39885427561)。安装配置回归、依赖预检、六校9入口编译、8组边界、5组结构和发布检查均通过。此结果对应所链接的提交，不代表未来提交或其他平台自动通过。

CI 显式设置全部七个可写 TeX 树，并检查实际目录均位于 runner 临时安装根目录内；仅设置 `TEXDIR` 不会使安装器自动重算其他树。科学宏包集合使用当前仓库存在的 `collection-mathscience`，而非不存在的 `collection-science`。

后续一次文档提交在自动选择的 `latex.us` 镜像获取 `texlive.tlpdb` 失败，未执行到模板测试。现将安装流程收敛到 `tests/ci_texlive.sh`：按顺序尝试 Illinois、MIT 两个明确 HTTPS 镜像，安装器下载限时重试、基础安装限时8分钟、宏包安装限时10分钟；同次尝试的安装器与宏包使用同一站点。失败尝试保留在各自临时目录，不导出到后续步骤；全部镜像失败时 CI 仍明确失败，不忽略错误。离线回归通过替身命令覆盖下载、安装、集合失败后的切换、版本与目录越界拒绝，以及成功才导出路径的行为；它不是对真实网络可用性的保证。最新提交的远端结果请查看 README 动态徽章所链接的实际运行。

工作流通过网络安装 TeX Live 并检查主版本2026，未锁定全部宏包快照或安装器摘要，因此不是严格可重现构建；未来网络切换年份应失败而非静默升级。托管 runner 带有预装系统工具，不等于全新操作系统容器；Windows或macOS仍未完成安装到编译的整链实测。依赖预检、本地字体隔离和托管 runner 验证也不能替代学校审核。
