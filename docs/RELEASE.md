# 发布清单

本目录是**公开源码副本**，不替代原本地档案。测试及导出脚本不会初始化Git、创建GitHub仓库、提交或推送；仓库发布由维护者显式操作。

## 已划定范围

- 六校本地新编写模板与9入口；自有内容MIT，海经衍生bst保留LPPL及全文。
- 官方资料只给链接及适用范围，不携带Word、国标全文、网页快照、原始压缩包。
- 不含海大/海师上游工程、旧封面或真实论文，也不带危险清理脚本。
- 不分发字体。默认使用发行版开放字体；学校模式须用户自行合法安装。
- 日志、PDF、测试产物留在本地并被忽略，不是首次源代码提交内容。

## 发布前须人工确认

1. 阅读LICENSE和THIRD_PARTY_NOTICES，确认署名和自有授权范围；法律与隐私判断不由自动脚本替代。
2. 运行预检、编译、边界、结构及发布检查，审阅`reports/release-manifest.json`。
3. 检查每个新增文件来源，尤其来源URL是否仍有效，声明占位是否被误认原文。
4. 若生成示例PDF/截图，重新审查文字层、个人信息与字体嵌入后再选择发布；默认PDF不入库。
5. 首次建立Git时先查看`git status --short`和`git diff --cached --stat`，不要对旧桌面档案直接`git add .`。
6. CI配置仅供之后真实运行；未实际运行前不得添加“CI已通过”的徽章或承诺。

## 导出无产物源码包

项目目录可能有本机生成但被忽略的PDF和日志，不应直接用文件管理器把整个目录打包。可运行：

```bash
python3 tests/export_source.py ../hainan-thesis-reference-source.zip
```

导出前先审查白名单，只复制受支持的源码/文档，排除reports、.build、PDF及缓存；目标必须在项目外且不存在，不覆盖旧包。不初始化Git、不上传。可以解压该包作为首次入库的干净副本；仍须人工审查许可和隐私。

公开工作稿可保留未取得原件的状态，但不能移除这些事实边界。后续收到授权或官方新版时单独审查，不直接把旧档案整目录搬进来。
